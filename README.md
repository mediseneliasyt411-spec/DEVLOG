# DEVLOG — Mi espacio de desarrollo personal

DEVLOG es una aplicación web para que un estudiante de Ingeniería en Sistemas Computacionales organice proyectos, registre habilidades y documente lo que aprende.


## Funcionalidades
- Panel principal con estadísticas personales.
- Registro de proyectos y tecnologías utilizadas.
- Seguimiento del avance de habilidades (0–100%).
- Bitácora para guardar aprendizajes.
- Diseño adaptable a computadora y celular.
- Persistencia local de los datos.

## Tecnologías
- HTML5: estructura semántica.
- CSS3: diseño adaptable, componentes y estilos.
- JavaScript: interacción, renderizado y lógica.
- localStorage: persistencia de información en el navegador.

## Estructura
- `index.html`: estructura de la aplicación.
- `styles.css`: estilos visuales.
- `app.js`: lógica y almacenamiento.
